Rivet 编程智能体

Git 仓库：https://github.com/STL250/agent

运行环境：Python 3.10 及以上，无运行时第三方依赖。

安装与运行：
1. 创建并激活虚拟环境：python -m venv .venv。
2. 安装项目：python -m pip install -e .。
3. 通过环境变量设置 RIVET_API_KEY 和 RIVET_MODEL；使用兼容网关时另设 RIVET_BASE_URL。
4. 启动：rivet -w 待修改的项目目录。进入后可连续追加需求，使用 /plan 查看任务计划、/status 查看状态、/diff 查看修改、/sessions 查看历史会话、/resume 恢复会话、/new 新建会话、/exit 退出。

示例项目位于 examples/demo_project。可运行：
rivet -w examples/demo_project
进入后输入：修复 calculator.py 中的 mean 函数，并运行测试验证

特色功能：Rivet 不使用 agent 框架或 SDK，直接实现 OpenAI 兼容的 Chat Completions 工具调用协议。Agent 本身维护持续会话，核心循环负责多轮上下文、模型输出解析、工具调度、结果回传和终止判断。复杂任务可通过 update_plan 建立可校验的步骤状态，TUI 实时展示进度；未完成计划不能直接结束，计划随会话保存和恢复。轻量彩色 TUI 集中展示模型、工作区、轮次、工具动作、命令摘要、验证状态和最终结果；重定向输出或设置 NO_COLOR 时自动使用纯文本。会话每轮原子保存到 Git 已忽略的 .rivet 目录，可恢复消息、计划、任务证据、修改差异及验证状态；不保存 API key 和含本机路径的系统提示。会话指纹防止跨项目误恢复，关闭期间的外部文件变化会使旧验证自动失效。本地工具支持计划更新、目录遍历、文件读写、文本搜索、精确替换、当前会话差异查看和命令执行。命令执行前后会比较有边界的工作区快照，识别脚本、格式化器等间接造成的新增、修改和删除，并接入 diff 与验证门禁；二进制、大文件或超限情况会明确标记追踪受限。所有工具参数在本地二次校验；修改文件后，只有最新修改之后的验证命令成功才能标记为已验证完成。长对话压缩会保留完整的工具调用-结果配对；网络异常会退避重试；空回复、无进展调用和最大步数均有终止策略。文件访问限制在指定工作区，写入采用原子替换，命令输出和运行时间均受限制；安装依赖、网络访问和本地 Git 写操作在 safe 模式下需要确认，递归删除、强制重置和对外推送始终拒绝。safe、ask 和 never 三种模式分别适用于常规自动执行、逐项确认和只读检查。

流式与中断：模型文本通过 SSE 实时显示，分片的工具名、调用 ID 和 JSON 参数按索引重组；不支持流式的兼容网关自动回退。Ctrl+C 取消当前模型请求、审批或命令并回到输入框，不退出会话。命令中断会终止子进程树、追踪取消前已产生的文件变化，且不会把不完整回复或取消的验证记为成功。

架构设计与安全边界见 docs/ARCHITECTURE.md。API key 仅通过环境变量或未入库配置文件提供，不得写入仓库或展示材料。
