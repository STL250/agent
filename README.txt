Rivet 编程智能体

Git 仓库：https://github.com/STL250/agent

运行环境：Python 3.10 及以上，无运行时第三方依赖。

安装与运行：首次在源码目录执行 python -m pip install -e .，并复制 .env.example 为 .env 填写模型配置。以后只需在任意项目根目录执行 rivet，即以当前目录启动 TUI；网页界面执行 rivet --web。配置自动查找用户目录 .rivet/.env、Rivet 源码目录 .env 和当前目录 .env，也可用 RIVET_ENV_FILE 或 --env-file 指定。终端输入 / 会显示可筛选的命令菜单，支持方向键选择与 Tab 补全；执行期间动态显示模型和工具的工作状态。输入 /skills 可查看当前可用及已使用的技能，/permissions [safe|ask|never] 可即时切换当前进程的审批策略。Web 顶栏提供相同的模式选择器；任务执行或等待审批期间不能切换，重启后仍以启动参数或 .env 为准。

模型接入：Rivet 通过 ClientFactory 隔离模型协议。当前 openai_chat 客户端支持兼容 Chat Completions 与 Function Calling 的云端网关和本地服务，可配置完整 endpoint、bearer/api-key/none 鉴权、附加请求 JSON、扩展请求头及需跨轮回传的响应字段，不在 Agent 中判断厂商。运行 rivet --check-model 可实际检查流式响应、工具调用和工具结果回传。配置示例见 docs/PROVIDERS.md。

特色功能：Rivet 不使用 agent 框架或 SDK，直接实现 OpenAI 兼容的 Chat Completions 工具调用协议。Agent 本身维护持续会话，核心循环负责多轮上下文、模型输出解析、工具调度、结果回传和终止判断。主 Agent 可把探索或审查任务委派给独立上下文的只读子 Agent，并收回结构化报告；所有文件修改与命令执行仍由主 Agent 负责，子 Agent 不能继续委派。两个独立只读任务支持受限并行。复杂任务可通过 update_plan 建立可校验的步骤状态；未完成计划不能直接结束，计划随会话保存和恢复。终端 TUI 与本地 Web UI 均可实时展示模型输出、计划、子 Agent、工具动作、改动和验证状态；Web UI 支持主动停止任务、安全 Markdown 与代码复制，以及按文件浏览的行级 Diff。会话每轮原子保存到 Git 已忽略的 .rivet 目录，可恢复消息、计划、子 Agent 报告、任务证据、修改差异及验证状态；不保存 API key 和含本机路径的系统提示。会话指纹防止跨项目误恢复，关闭期间的外部文件变化会使旧验证自动失效。本地工具支持计划更新、子任务委派、目录遍历、文件读写、文本搜索、精确替换、当前会话差异查看和命令执行。命令执行前后会比较有边界的工作区快照，识别脚本、格式化器等间接造成的新增、修改和删除，并接入 diff 与验证门禁；二进制、大文件或超限情况会明确标记追踪受限。所有工具参数在本地二次校验；修改文件后，只有最新修改之后的验证命令成功才能标记为已验证完成。长对话压缩会保留完整的工具调用-结果配对；网络异常会退避重试；空回复、无进展调用和最大步数均有终止策略。文件访问限制在指定工作区，写入采用原子替换，命令输出和运行时间均受限制；安装依赖、网络访问和本地 Git 写操作在 safe 模式下需要确认，递归删除、强制重置和对外推送始终拒绝。safe、ask 和 never 三种模式分别适用于常规自动执行、逐项确认和只读检查。

Skills：启动新会话时，Rivet 会发现内置技能、用户目录 ~/.rivet/skills 和当前项目 .rivet/skills 下的 SKILL.md；同名时项目级优先。模型平时只接收名称与描述，任务明确匹配或用户点名后才调用 activate_skill 加载正文，需要时再读取列出的文本资源。技能不能提升权限、越出目录或自动执行资源，其使用历史会随会话保存，并在 TUI /skills 和 Web「活动」面板中展示。项目技能目录可提交到 Git，但 .rivet 下的会话和其他运行状态仍保持忽略。

流式与中断：模型文本通过 SSE 实时显示，分片的工具名、调用 ID 和 JSON 参数按索引重组；不支持流式的兼容网关自动回退。Ctrl+C 取消当前模型请求、审批或命令并回到输入框，不退出会话。命令中断会终止子进程树、追踪取消前已产生的文件变化，且不会把不完整回复或取消的验证记为成功。

架构设计与安全边界见 docs/ARCHITECTURE.md。API key 仅通过系统环境变量或 Git 已忽略的 .env 提供，不得写入源代码、仓库或展示材料。
